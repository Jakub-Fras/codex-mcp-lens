Why review these entries?

Apps (connectors) and MCP servers can let Codex read information or make changes for you. What each can do depends on its settings and the access you gave it. If you no longer recognise or need one, review it in Codex and, for an app, in that app’s account settings.

The triangle is a reminder to review the list. It does not mean MCP Lens found a problem.

What is listed here?

App (connector): an app Codex can use to reach a service such as Notion; being listed does not prove your account is connected. MCP server: a separate source of tools for Codex that may run on this device or at a URL. Plugin: a package that can provide an app or MCP server. Skill: saved instructions for a task. Hook: an action Codex can run when an event happens. Built-in Codex feature: a tool supplied by Codex itself, shown separately below.

This is a view of Codex on this computer. An app connected in ChatGPT may still be usable there even if it is off here or absent from this report.

How to read this report
  1. Name and type: each entry says whether it is an app (connector), an MCP server, or a built-in Codex feature.
  2. On in Codex: Codex lists an app as enabled and shows actions for it. That does not confirm an outside account is connected or that this folder allows the app.
  3. Activity: a recorded request means Codex asked it to do something in saved history. The request may have failed. No matching request is not proof it was never used.
  4. Find it: open an entry and read “Where did we find it?” for its exact settings or plugin file and, for plugins, where to look in Codex.
  5. Stop or remove: open an entry and read “What can you do?” The available buttons depend on how the entry was installed. Buttons work in the report opened by the launcher.
  6. Outside accounts: turning an app off in Codex does not disconnect the account it may use. Each app has a separate account step.

The report cannot confirm which account, pages, files, or records an outside app or MCP server can reach.

The first two counts can include the same app: one counts saved requests, and the other counts apps Codex currently lists as on with actions. Saved activity on this device may be incomplete, so no matching request does not prove an app or MCP server was never used.
